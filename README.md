# c-chat

c-chat 是一个基于 Vue3、Element Plus、axios 的聊天应用。  
后端采用Go实现，调用各种模型API，后端地址：https://github.com/eaglecc/c-chat

对接多种大模型
| 模型 | 描述 | 备注 |
| ---- | ---- | ---- |
| DeepSeek | DeepSeek-Chat   | ✅ |
| DeepSeek | DeepSeek-R1   | ✅ |
| ChatGPT |    | ❌  |
| 元宝|    |  ❌ |
| 豆包|    | ❌  |

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```
